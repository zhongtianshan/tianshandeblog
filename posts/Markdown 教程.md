# Markdown 完全教程

Markdown 是一种轻量级标记语言，用简单的符号就能排版，适合写文档、笔记、博客、README 等。

---

## 1. 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

> 一个 `#` 是一级，最多六个 `#`。

---

## 2. 文本样式

```markdown
**粗体**       用两个星号包起来
*斜体*         用一个星号包起来
***粗斜体***   用三个星号
~~删除线~~     用两个波浪线
`行内代码`     用反引号包起来
<u>下划线</u>  用 HTML 标签
```

效果：**粗体**、*斜体*、***粗斜体***、~~删除线~~、`行内代码`、<u>下划线</u>

---

## 3. 列表

### 无序列表

```markdown
- 苹果
- 香蕉
- 橘子
  - 嵌套缩进两个空格
  - 继续
```

### 有序列表

```markdown
1. 第一步
2. 第二步
3. 第三步
```

### 任务列表

```markdown
- [x] 已完成的事
- [ ] 未完成的事
- [ ] 另一件待办
```

- [x] 已完成的事
- [ ] 未完成的事

## 4. 链接

```markdown
[显示文字](https://example.com)
[带标题的链接](https://example.com "鼠标悬停提示")

直接显示链接：<https://example.com>
```

---

## 5. 图片

```markdown
![图片描述](图片路径)
![本地图片](C:\Users\pytho\Pictures\steve.png)
![网络图片](https://example.com/image.png)
```

> 图片和链接的区别就是前面多了个 `!`。

## 6. 引用

```markdown

> 多行引用每行都加 `>`。
>
>> 引用里可以嵌套引用。

> 引用里可以包含 **其他语法** 和 `代码`。
```

> 这是一段引用。
>
> > 嵌套引用。

## 7. 代码块

### 行内代码

```markdown
用 `print("hello")` 打印。
```

### 代码块（三个反引号 + 语言名）

````markdown
```python
def hello():
    print("Hello, Markdown!")
```

```javascript
console.log("Hello!");
```

```bash
echo "Hello"
```
````

```python

    print("Hello, Markdown!")
```

## 8. 表格

```markdown
| 左对齐 | 居中对齐 | 右对齐 |
|:-------|:--------:|-------:|
| 内容1  | 内容2    | 内容3  |
| 内容4  | 内容5    | 内容6  |
```

| 语法 | 说明 | 示例 |
|:-----|:----:|:----|
| `-`  | 短横线 | 分隔线/无序列表 |
| `#`  | 井号 | 标题 |
| `**` | 双星号 | 粗体 |

---

## 9. 分隔线

```markdown
---
***
___
```

三条或以上的 `-`、`*`、`_` 都能画出分隔线。

---

## 10. 转义字符

想显示特殊符号本身时，前面加 `\`：

```markdown
\*这不是斜体\*
\# 这不是标题
```

---

## 11. 脚注

```markdown
这里需要解释[^1]。

[^1]: 这里是脚注的内容。
```

---

## 12. 高级技巧

### 折叠内容 (HTML)

```html
<details>
<summary>点击展开</summary>

这里是折叠的内容，支持 Markdown 语法。

```python
print("隐藏的代码")
```
</details>
```

<details>
<summary>点击展开</summary>

这里是折叠的内容。
</details>

### 锚点跳转

```markdown
[跳转到标题](#1-标题)
```

### 表情符号

```markdown
:smile: :heart: :+1: :rocket:
```

## 常用编辑器推荐

| 编辑器 | 平台 | 特点 |
|--------|------|------|
| **MarkText** | 全平台 | 开源、WYSIWYG、类 Typora |
| **Typora** | 全平台 | 沉浸式写作，收费但好用 |
| **TizuMark** | Windows | 轻量 ~7MB，速度快 |
| **VS Code** | 全平台 | 加插件可实时预览 |
| **Obsidian** | 全平台 | 笔记型，双向链接强大 |
